==============================================================================
COMMANDS                                                    *notes-commands*

:TemplateInsert [name]   Inject template `name`, or open the picker.
:TemplateReload          Re-read the templates directory.
:NotesVault              Print the detected vault root.
:NoteNew [name]          Create a note in new_note_dir.
:NoteMove [dir]          Move the current note to dir (picker if omitted).
:NoteOutline [maxlevel]  Heading outline picker for the current buffer.
:NoteOutlineToggle       Toggle the outline sidebar.
:NoteEmbedPreview        Preview the embed under the cursor.
:NoteEmbedInline         Toggle inline note embeds.
:NoteImageToggle         Toggle inline images in this buffer.
:NoteImageStatus         Show image rendering capabilities.

==============================================================================
KEYMAPS                                                      *notes-keymaps*

<leader>mt   Template picker
<leader>ml   Link a file
<leader>mh   Link a header (file, then header)
<leader>mn   New note (global)
<leader>mm   Move note to another directory
<leader>mo   Outline picker
<leader>mO   Outline sidebar
<leader>me   Preview embed under cursor
<leader>mE   Toggle inline note embeds
<leader>mi   Toggle inline images
<leader>mb   Back through followed links
<leader>mr   Reload templates
<leader>mv   Print vault root
gf           Follow markdown link under cursor
