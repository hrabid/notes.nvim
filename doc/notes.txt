==============================================================================
COMMANDS                                                    *notes-commands*

:TemplateInsert [name]   Inject template `name`, or open the picker.
:TemplateReload          Re-read the templates directory.
:NotesVault              Print the detected vault root.
:NoteNew [name]          Create a note in new_note_dir.
:NoteMove [dir]          Move the current note to dir (picker if omitted); links are updated.
:NoteRename [name]       Rename the current note; links are updated.
:NoteBacklinks           Notes that link to the current note.
:NoteCheck [file]        Broken links / missing headings -> quickfix.
:NoteDaily [offset|date]  Open a daily note.
:NoteWeekly [offset|date] Open a weekly note.
:NoteNext / :NotePrev    Step through daily/weekly notes.
:NotePasteImage [name]   Save the clipboard image and link it.
:NoteSearch [text]       Search the vault's text.
:NoteTags [tag]          Browse tags.
:NoteProps [key[=value]] Browse frontmatter properties.
:NoteToc [maxlevel]      Insert/update the table of contents.
:NoteFollow [split|vsplit|tab]  Follow the link in a new window.
:NoteLinkConvert [wiki|markdown]  Convert link style (cursor / whole buffer).
:NoteTask                Toggle checkbox(es).
:NoteTasks [open|done|all|file]  Task picker.
:NoteReindex             Rebuild the vault index.
:NoteOutline [maxlevel]  Heading outline picker for the current buffer.
:NoteOutlineToggle       Toggle the outline sidebar.
:NotePreview             Preview the link/embed under the cursor.
:NoteEmbedInline         Toggle inline note embeds.
:NoteImageToggle         Toggle inline images in this buffer.
:NoteImageStatus         Show image rendering capabilities.
